### Самое важное для "приложение, а не сайт":
- **Сейчас:** `Cbopka.exe` 87MB — это Node сервер + клиент, но открывает браузер
- **Нужно:** Electron `Cbopka-portable.exe` 150MB — настоящее окно, иконка, трей, без браузера
- **Идеально:** Tauri 10MB — нативное окно, быстрое, легкое
- **Телефон:** APK 5MB через Capacitor или PWA "Установить приложение"

**Что делать прямо сейчас:**
1. Скачай новый exe: https://raw.githubusercontent.com/gggvkvh405-rgb/Cbopka/release-exe/Cbopka.exe
2. Для нативного окна без браузера: `cd electron && npm install && npm run build:win` → получишь настоящее приложение
3. Для телефона: открой сайт в Chrome → Установить приложение (PWA) — уже работает как APK
